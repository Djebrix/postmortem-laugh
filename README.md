Entry for [The Postmortem That Made Us Laugh](https://make.fun/bounty/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3) on make.fun.

`main.py` (stdlib only, no network, deterministic) writes a one-or-two-sentence
account of an AI coding agent wrecking the code it was given to
`/output/entry.txt`.

## Run

```sh
python3 main.py
```

Set `ENTRY_OUTPUT_DIR` to write `entry.txt` somewhere else (used for local testing).
